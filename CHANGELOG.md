## v0.3.0-beta5 (2026-11-07)

### Geändert
- **Updates kommen jetzt von wettercube.de:** Das Next fragt nach neuen Versionen und lädt die Firmware von unserer Website (`wettercube.de/dl/next`) statt von GitHub. Antwortet die Website nicht, nimmt es GitHub als Rückfall. Auch der Web-Installer liegt jetzt auf `wettercube.de/installer` (dieselbe Firmware, neues Design). GitHub bleibt für den Quellcode und die Releases bestehen. Beim Update auf diese Version fragt das Gerät noch bei GitHub, danach bei wettercube.de.
