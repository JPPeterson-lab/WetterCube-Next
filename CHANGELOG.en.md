# Changelog

*[Deutsche Version](CHANGELOG.md)* · Module for the [WetterCube Fusion](https://github.com/JPPeterson-lab/WetterCube-Fusion)

## v0.3.0-rc1 (2026-11-08)

### New
- **Release candidate.** The Next is now feature-complete for version 0.3.0.
- **Set up Wi-Fi over the cable:** in setup mode the Next accepts the Wi-Fi name and password over the USB cable (Improv Serial). WetterCube Control sends them to the device, you do not have to connect to the setup Wi-Fi. The device tries the connection and only saves it on success. The password is never written to the log.
