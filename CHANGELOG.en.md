# Changelog

*[Deutsche Version](CHANGELOG.md)* · Module for the [WetterCube Fusion](https://github.com/JPPeterson-lab/WetterCube-Fusion)

## v0.3.0-beta2 (2026-10-28)

### New
- **Lower half of the first page is selectable:** rooms and biometeorology side by side (as before), rooms only, or biometeorology only. A single tile uses the full width, so names are no longer truncated. Set on the Next's own page ("Erste Seite, unten"). A Fusion from v1.0.0-rc2 and a newer Apex also show the option in this Next's tab and control it when they manage the device; with an older Fusion the setting on the Next applies.
